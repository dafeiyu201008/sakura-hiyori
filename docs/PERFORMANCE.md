# 性能记录

## 测试环境

- 浏览器：Chrome（headless，GPU 加速）
- 分辨率：1920×1080，DPR 2.0（内部渲染 3840×2160）
- 画质档：画质（high）
- 帧率：60 FPS
- 时段：夜晚 22:00，庭院主视角

## 结果

| 项目 | 数值 |
|---|---|
| 页面读数 | 60.0 FPS |
| DPR | 2.00 |
| 画质档 | 画质（high） |
| 模型体积 | 36 MB（网页优化版：Draco + WebP 2K） |
| 首屏加载 | 约 3 秒（本地服务器，31 MB 模型） |

## 画质档位

| 档位 | 策略 |
|---|---|
| 自动 | 按设备能力选择 DPR 与帧率 |
| 画质 | 优先清晰度，DPR 2.0，60 FPS |
| 均衡 | 降低 DPR 或阴影质量，保持 60 FPS |
| 省电 | 最低 DPR 与 30 FPS，适合移动端 |

## 说明

- 以上为本地无头浏览器实测；真实设备会因 GPU、屏幕分辨率与后台负载不同而有差异；
- 场景未暴露 draw call / 三角形统计接口，暂未记录；
- 若需要更精确的帧时间分布，可用 Chrome Performance 面板录制。
