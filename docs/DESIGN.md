# 设计说明

## 概念

「桜水日和」是一座日式水岸小屋的微缩模型：樱花树、木屋、溪流与锦鲤、石灯笼、风铃、纸拉门。
场景不是写实重建，而是把「春日午后到夜晚」的庭院气氛压缩成一个可以拿在手里看的立体模型。

## 美术方向

- 低饱和、偏纸感的材质，木、纸、石三种主材质；
- 暗背景 + 暖窗光，让樱花与灯笼成为画面里的亮点；
- 水面、玻璃罩、风铃使用半透明材质，增加层次；
- 樱花不是静态装饰：三棵树都可点击，花瓣会成片落下。

## 时段系统

四个预设时段：

| 时段 | 时间 | 视觉 |
|---|---|---|
| 清晨 | 07:00 | 冷色天光、薄雾感、低对比 |
| 正午 | 12:00 | 明亮、阴影短、色彩最饱和 |
| 黄昏 | 18:00 | 暖橙色光、长阴影、窗光开始明显 |
| 夜晚 | 22:00 | 深蓝背景、暖色灯笼与窗光为主光源 |

实现方式：用关键帧插值驱动背景色、半球光、主光、轮廓光、室内光、材质自发光与曝光；拖动时间滑杆可在 07:00–22:00 之间连续过渡。

## 交互设计

- **樱树**：三棵树分别对应 260 / 160 / 90 片花瓣，点击后成片落下，并显示提示；
- **门与入室**：点击门扇开合；门全开后出现「入室」，进入茶室后镜头限制在小范围环视，可退出；
- **水面**：点击产生涟漪；
- **风铃 / 玻璃罩**：点击触发声音或玻璃罩开合；
- **纯享**：隐藏全部界面，保留画面，可保存单帧照片。

## 镜头设计

六个手动机位，覆盖庭院的不同观看方式：

| 机位 | 用途 |
|---|---|
| 庭院主视角 | 全景，交代整体 |
| 溪石听水 | 溪流、石桥、锦鲤 |
| 花下观树 | 樱树与花雨 |
| 檐影闻铃 | 屋檐、灯笼、风铃 |
| 穿桥见院 | 桥与平台 |
| 茶室入口 | 门廊与室内 |

镜头之间用缓动补间，避免瞬移；拖拽、滚轮、右键平移可自由调整。

## 声音

三路音源：风、水、铃。提供总音量控制与一键开关；夜晚时段声音更明显。

## 性能

四档画质（自动 / 画质 / 均衡 / 省电），帧率可选 60 / 30；按设备选择 DPR 与阴影质量。
设计目标：桌面 1920×1080 画质档稳定 60 FPS，移动端自适应 30–60 FPS。

## 技术栈

- three.js 0.169 + WebGL2
- GLTFLoader + DRACOLoader
- 单页 HTML + 两个模块化 JS（bundle 负责场景构建，entry 负责交互）
- 模型资产 GLB（网页优化版 36 MB；原始 167 MB 另行提供）
